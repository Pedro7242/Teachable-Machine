O modelo foi treinado no **Teachable Machine** para identificar três situações:

* Pessoa usando óculos
* Pessoa usando fone
* Pessoa sem óculos e sem fone

A aplicação usa a webcam para analisar a imagem e identificar em qual categoria a pessoa se encaixa.

## Modelo

Foram utilizadas imagens das três categorias para que a IA aprendesse a diferenciar cada situação.

Depois do treinamento, o modelo foi exportado e utilizado na aplicação.

Eu fiz usando minha própria webcam.

Enquanto eu fazia, o modelo cometeu alguns, principalmente por causa que eu não coloquei dados suficientes,
mas eu refiz e ele funcionou normalmente.
